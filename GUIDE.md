# TgAuto: установка на телефон (root не нужен)

## 1. Termux
- Скачай Termux с F-Droid (f-droid.org) или с GitHub (github.com/termux/termux-app/releases).
- Версия из Play Маркета не подойдёт, она устаревшая.

## 2. Claude Code в Termux
Открой Termux и вводи команды по одной:
```
pkg upgrade -y
pkg install -y libc++ nodejs
node -v
DISABLE_AUTOUPDATER=1 npm i -g @anthropic-ai/claude-code@2.1.112
mkdir -p ~/.claude && echo '{"env":{"DISABLE_AUTOUPDATER":"1"}}' > ~/.claude/settings.json
```
- Если Termux спросит про замену конфигов, жми Enter.
- `node -v` должен показать версию. Если вместо неё ошибка `CANNOT LINK EXECUTABLE`, ещё раз выполни первые две строки.
- Версия Claude Code нужна именно 2.1.112, новые в Termux не запускаются.

## 3. Вход в Claude
- Введи `claude` и выбери вход через аккаунт Claude.
- Откроется ссылка: войди в браузере, скопируй код и вставь его обратно в Termux.
- Выйди командой `/exit`.
- Проверь: `claude -p "скажи ок"`. Если ответил, всё работает.

## 3б. Gemini (по желанию, запасной вариант)
Если Claude недоступен, скрипты возьмут Gemini. Нужен обычный аккаунт Google, ключ API не нужен.
```
pkg install -y python make clang
npm install -g @google/gemini-cli --ignore-scripts
gemini --version
```
- `--ignore-scripts` обязателен: без него установка падает на сборке `tree-sitter` (ошибка про `android_ndk_path`). Для работы это не нужно.
- Если новая версия всё равно не запускается, поставь старую: `npm install -g @google/gemini-cli@0.2.2 --ignore-scripts`. Есть и сборка для Termux: github.com/DioNanos/gemini-cli-termux.
- Введи `gemini` и выбери **Login with Google** (Sign in with Google).
- Gemini покажет ссылку. Открой её в браузере телефона и войди в Google. Страница потом перейдёт на `localhost`: это тот же телефон, так и должно быть, вернись в Termux.
- Если Gemini просит вставить код, скопируй его со страницы и вставь в Termux. Если браузер сам не открывается, запусти так: `NO_BROWSER=true gemini`.
- Выйди командой `/quit`.
- Проверь: `gemini -p "скажи ок"`. Если ответил, всё работает.

## 4. Разрешить TgAuto управлять Termux
```
mkdir -p ~/.termux && echo "allow-external-apps=true" >> ~/.termux/termux.properties
termux-reload-settings
```

## 5. TgAuto
- Установи `TgAuto-1.7.apk`.
- При запуске разреши уведомления и «Выполнять команды в Termux».
- В настройках телефона отключи оптимизацию батареи для **Termux** и **TgAuto**: Приложения → Батарея → Без ограничений.

## 6. Ключи Telegram
- Зайди на my.telegram.org → API development tools → создай приложение (название любое).
- Скопируй **api_id** и **api_hash**.

## 7. Вход в Telegram
- В TgAuto открой вкладку «Аккаунт» и вставь api_id и api_hash.
- Введи номер, потом код из Telegram, потом пароль 2FA, если он есть.

## 8. Проверка Claude и Gemini
- Открой «Настройки» → LLM и выбери порядок: «Claude, потом Gemini», «Только Claude», «Только Gemini» или «Только API-ключ».
- Нажми «Проверить» у нужного аккаунта. Должно прийти «ок».
- Ключ Anthropic внизу нужен только как последний запас, можно оставить пустым.

## 9. Скрипты
- Открой вкладку «Скрипты» и нажми «Выбрать папку». Создай, например, `Documents/Scripts`.
- Положи в эту папку скрипты (они лежат в отдельном репозитории TgAutoS (github.com/vipa-ch-cloud/TgAutoS): папки `automod` и `autoresponder`).
- На карточке скрипта нажми «Зависимости», потом «Запустить».
- Папки скриптов лежат в личной памяти приложения: `/data/data/com.v1pach.telescript/files/config/<имя>` и `.../files/data/<имя>`. Туда есть доступ только с root. Для автоответчика: `profile.json` в `config/autoresponder`, `state.json` и `style.json` в `data/autoresponder`. Без root это не нужно: скрипт создаст свои файлы сам.

## 10. Автомод в чате
Твой аккаунт должен быть админом в чате, в котором стоит Ирис. Команды пиши прямо в чате:
- `.automod`: включить автомод в этом чате.
- `.automod -r=ссылка`: включить и взять правила по ссылке.
- `.automod -d`: убрать автомод из этого чата.
- `.automod off`: выключить (чат остаётся в списке).
- `.automod status`: показать, включён ли автомод.
- `.context N`: сколько сообщений смотреть в одной проверке (N это число).
- `.ams`: проверить чат прямо сейчас.

## 11. Автоответчик
- Во вкладке «Скрипты» выбери папку со скриптом `autoresponder`, потом «Зависимости».
- Отдельный вход не нужен: скрипт берёт сессию TgAuto (вкладка «Аккаунт», шаг 7). QR сканировать не надо.
- Команды в любом чате:
  - `.start`: включить ответы в этом чате.
  - `.start imit`: включить с имитацией твоего стиля.
  - `.stop`: выключить.
  - `.mem`: показать, что бот помнит.
  - `.ign`: игнорировать этот чат.
  - `.noign`: перестать игнорировать.
  - `.reload`: перечитать настройки и профиль.
- На голосовые сообщения бот отвечает «опять гс».

## 12. Кнопка «Конфиг»
- У скрипта с настройками на карточке есть кнопка «Конфиг» (у automod и автоответчика она есть).
- Меняй переключатели, числа, текст, списки и выбор, потом нажми «Сохранить». «Сбросить к умолчаниям» ставит значения по умолчанию, но пока не сохраняет.
- Сохраняются только показанные настройки, остальное в файле не трогается. Ключи и пароли здесь не показываются.
- Изменения применятся после перезапуска скрипта.
- Свой скрипт-папка получает кнопку, если рядом лежит `config.schema.json` (формат смотри в `config.schema.json` у automod).

## 13. Провайдеры: DeepSeek, OpenAI, свой API (только сборка TgAuto Nightly)
Этот раздел появился в Nightly (`TgAuto-nightly-*.apk`, ставится рядом со стабильной). В стабильной сборке настройки LLM остались прежними.
Если Claude и Gemini не нужны или недоступны, скрипты могут ходить в любой OpenAI-совместимый сервис.
- «Настройки» → «Провайдеры» → нажми «DeepSeek», «OpenAI» или «Свой API».
- DeepSeek: ключ создаётся на platform.deepseek.com → API keys. Адрес `https://api.deepseek.com`, модель `deepseek-chat` уже подставлены. Нужен положительный баланс.
- Свой API (например, tokenlavka): адрес берёшь из кабинета сервиса, обычно он заканчивается на `/v1`, например `https://tokenlavka.example/v1`. Вставь ключ и название модели. Кнопка «Загрузить список моделей» покажет доступные.
- Нажми «Проверить»: придёт короткий ответ или текст ошибки (401 значит неверный ключ, 404 неверный адрес или модель).
- Порядок в списке кнопками вверх и вниз: скрипты пробуют провайдеров сверху вниз.
- Приватность: ключи лежат только в закрытой папке приложения на телефоне (файл с правами 600). Они не пишутся в логи, не показываются после сохранения и не попадают в папку скриптов. Скрипт получает только путь к файлу в `TELESCRIPT_LLM_PROVIDERS_FILE`, сам файл читает тот скрипт, который ты запустил.
- Codex (аккаунт ChatGPT) пока не поддерживается: официальный вход в Termux у многих не проходит (github.com/openai/codex/issues/6632), проверенного способа нет.

## 14. Консоль и выбор ИИ-бэкенда (только сборка TgAuto Nightly)
В стабильной сборке этих разделов нет.
- «Настройки» → «CLI» (самый верх) → «Открыть консоль»: полноэкранный терминал. Команды идут в Termux через тот же мост, что у скриптов, поэтому нужны Termux и разрешение RUN_COMMAND (раздел 4).
- Быстрые кнопки: «проверить claude», «проверить gemini», «версии node». Есть история (стрелки вверх и вниз), Ctrl+C и копирование: тап по строке выделяет её, кнопка копирования берёт выделенное или всё.
- Цвета ANSI (SGR) и переводы строк поддерживаются. Ограничение: вывод появляется только когда команда завершилась (фоновый RUN_COMMAND не стримит), а интерактивные программы (vim, ввод пароля) не работают. Ctrl+C перестаёт ждать и посылает завершение процессу.
- «Настройки» → «ИИ-бэкенд»: кто отвечает скриптам. «Авто» (Claude, затем Gemini, затем провайдеры, затем API; у каждого пункта есть переключатель и стрелки порядка), «Только Claude», «Только Gemini» или один конкретный провайдер.
- Что выбор реально делает: невыбранные claude и gemini скрываются от скриптов, скрипту отдаётся файл провайдеров только с выбранными, ключ Anthropic API передаётся, только если API выбран. Порядок внутри «Авто» передаётся в `TELESCRIPT_LLM_BACKEND` и действует там, где скрипт его учитывает. Собственный `backend` в конфиге скрипта по-прежнему приоритетнее. Контракт `TELESCRIPT_LLM_PROVIDERS_FILE` не менялся.
- После обновления со старой версии выбор берётся из прежней настройки порядка, пока ты ничего не поменяешь.
- Эффект консоли: кнопка «CRT-эффект» в шапке консоли (по умолчанию включён, запоминается) добавляет бегущую полосу обновления, строки развёртки, виньетку и мягкое свечение.
- Codex (Nightly): переключатель «Codex» в «ИИ-бэкенде» добавляет его в «Авто», либо выбери «Только Codex». Работает через Termux, как Claude; вход: `codex login` там же. На реальном устройстве не проверено.
- Секрет прокси: для MTProxy принимается hex (можно с dd/ee) или base64; пробелы убираются, неверный секрет даёт понятную ошибку вместо сообщения Python.
- Скрипты (automod, автоответчик): спам переподключений Telegram в логе сводится к строкам «нет связи» / «связь восстановлена».

## 15. Обновления OTA и магазин скриптов (1.9)

Настройки > Обновления (OTA): установка подписанного `.tgadyn` из файла, проверка релизов GitHub, автопроверка (по умолчанию вкл, только уведомление), автоприменение (по умолчанию выкл), откат, сброс на встроенную версию. OTA меняет Python-слой, схемы конфигов, строки и документацию; Kotlin-интерфейс, манифест и нативные библиотеки только новым APK. После двух неудачных запусков откат автоматический.

Вкладка «Скрипты» > «Магазин»: каталог из vipa-ch-cloud/TgAutoS с поиском, тегами, карточкой, установкой, обновлением, откатом и удалением. Настройки и данные скрипта при этом не затираются. Автообновление скриптов по умолчанию выключено и касается только проверенных скриптов без новых сетевых адресов. Файл `.tgascript` можно поставить вручную; непроверенный или неподписанный показывает предупреждение (разрешения, адреса, sha256, автор) и требует галочки. Сервера загрузки нет: свой скрипт предлагают через GitHub issue, владелец проверяет и ставит метку «Проверен». Подробности: docs/OTA.md.

### Источники сообщества и карточки (1.9.1)
Магазин показывает карточки с цветом, иконкой, версией, автором, датой и ссылкой на репозиторий. Кнопка «Источники»
позволяет добавить чужой каталог (URL index.json, https) и необязательный ключ Ed25519 (64 hex). Чужие источники
никогда не получают «проверено/официально»; без ключа они неподписанные, с предупреждением. Проверки sha256,
разрешений и подтверждение установки те же. Обновления из чужих источников — только вручную.
OTA подгружает только .tgadyn из releases/latest репозитория TgAuto; APK приложение само не скачивает и не ставит.

## Если не работает
- `CANNOT LINK EXECUTABLE "node"`: выполни `pkg upgrade -y`, затем `pkg install -y libc++ nodejs`.
- «Проверить» пишет `bad interpreter: No such file or directory`: выполни в Termux `pkg install -y libc++ nodejs` и перезапусти Termux. TgAuto уже запускает CLI через `node`, но без node ничего не заработает.
- «Проверить» пишет «не установлен» или `not found`: нужного CLI нет в Termux, поставь его по шагу 2 (Claude) или 3б (Gemini).
- `claude` выдаёт «Bad system call» или «native binary not installed»: встала не та версия, повтори установку с `@2.1.112`.
- «Проверить» молчит: открой Termux, чтобы он висел в фоне, и попробуй ещё раз.
- `gemini` падает при установке с `android_ndk_path` или `tree-sitter`: ставь с `--ignore-scripts`, см. шаг 3б.
- «Проверить» у Gemini пишет про вход: запусти `gemini` в Termux и войди заново через Login with Google.
- Gemini отвечает про квоту: у бесплатного аккаунта есть дневной лимит, подожди или выбери «Только Claude».
- Ошибки скриптов смотри во вкладке «Логи».

Каждому нужны свои аккаунт Claude и api_id/api_hash: шаги 3 (и 3б, если нужен Gemini) и 6 делаешь сам.
